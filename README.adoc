= Luix Passport

This project provides a standard authorization server based on https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-07#section-1.1[OAuth 2.1 Authorization Server], featuring a resource server and client configuration powered by Spring Authorization Server and Spring Boot 4. It supports traditional credentials login as well as social login integrations.

[[features]]
== Features

* **OAuth 2.1 Authorization Server**: Built on top of Spring Authorization Server with standard protocol support.
* **Social Login Support**:
** Google
** GitHub
* **Team Management**: Full-featured team capabilities including creating teams, inviting members, and managing team roles (`TEAM_OWNER`, `TEAM_MEMBER`).
* **RBAC (Role-Based Access Control)**: Fine-grained permission management using Roles and Permissions entities.
* **Security Audit Logs**: Comprehensive tracking of login events (success/failure), security actions, and threat monitoring.
* **User Management**: Profile management, avatar upload, and customizable user settings.
* **Modern Frontend**: A responsive and aesthetic UI built with React 19, Vite, and Tailwind CSS.
* **API Documentation**: Integrated OpenAPI (Swagger) documentation for easy API exploration.

[[using-docker]]
== Quick Start (Docker)

Evaluate the full stack locally with a single command.

=== 1. Build Docker Images
Run the following command in the project root directory:
```bash
npm run docker:build
```
* Or if using an ARM (Apple Silicon) machine:
```bash
npm run docker:build:arm64
```

=== 2. Start Application Stack
Starts the Authorization Server, Resource Server, Client, and PostgresSQL database:
```bash
npm run all:up
```

To stop the stack:
```bash
npm run all:down
```

[[social-login]]
== Social Login Configuration
To enable social login, configure `src/main/resources/config/application.yml` or set the corresponding environment variables.

=== Google
Set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`.

* **Redirect URI**: `http://localhost:4001/login/oauth2/code/google-idp`

=== GitHub
Set `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET`.

* **Redirect URI**: `http://localhost:4001/login/oauth2/code/github-idp`
